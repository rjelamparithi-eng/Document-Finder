================================================================================
ARAM OFFICE - DEPLOYMENT AND SETUP GUIDE
Hosting on Render with Aiven MySQL (or Railway)
================================================================================

1. PROJECT OVERVIEW
This guide outlines the deployment steps for the Aram Office Document Finder.
The production system runs on Render (as a Web Service) with Aiven MySQL
(as a managed cloud database). It also supports Railway or any standard Docker
container environment.


2. SOFTWARE REQUIREMENTS
- A GitHub account and Git installed locally
- A Render account (https://render.com) or Railway account (https://railway.app)
- An Aiven account (https://aiven.io) or cloud MySQL instance
- Java 21 JDK for local testing


3. TECHNOLOGIES USED
- Docker with Eclipse Temurin JDK 21 runtime
- MySQL 8.x with JDBC Driver (mysql-connector-j-8.4.0.jar)
- SSL/TLS database connectivity (DatabaseConnection.java handles Aiven certificates)
- Plain HTTP/REST backend using com.sun.net.httpserver


4. HOW TO RUN LOCALLY
Before deploying online, test the application locally:
1. Start your local MySQL database (e.g., MariaDB or XAMPP on port 3306).
2. Open a terminal in the project directory.
3. Start the server:
   .\RUN_WEBSITE.bat
4. Open http://127.0.0.1:8080 in your browser.
5. Run the test suite:
   .\RUN_TESTS.bat


5. MAIN FEATURES IN CLOUD DEPLOYMENT
- Containerized startup: Docker automatically builds and runs the Java server.
- Dynamic port binding: The server reads the $PORT environment variable assigned
  by Render or Railway (defaults to 8080 if not set).
- Automatic table initialization: DatabaseConnection.java automatically runs
  table creation on startup if tables do not exist.
- Seed data migration: Pre-existing synthetic documents and initial accounts are
  migrated to MySQL on initial boot.
- SSL/TLS Support: Aiven SSL connection parameters (sslMode=REQUIRED) are
  automatically supported.


6. DATABASE DETAILS & ENVIRONMENT VARIABLES
Configure these environment variables in your cloud hosting provider:

Option A (Single Connection URI):
  MYSQL_URL=mysql://<user>:<password>@<host>:<port>/<dbname>?sslMode=REQUIRED

Option B (Individual Variables):
  MYSQLHOST=<host>
  MYSQLPORT=<port>
  MYSQLUSER=<user>
  MYSQLPASSWORD=<password>
  MYSQLDATABASE=<dbname>

Render / Railway also supplies:
  PORT=<assigned_port>


7. STEP-BY-STEP DEPLOYMENT ON RENDER WITH AIVEN MYSQL

Step 1: Set Up Cloud MySQL on Aiven
1. Log in to Aiven (https://aiven.io) and create a free MySQL service.
2. Note the Service URI, Host, Port, User, and Password from the dashboard.
3. Under service settings, ensure public network access is allowed.

Step 2: Push Repository to GitHub
1. Ensure your repository root has:
   - Dockerfile
   - lib/mysql-connector-j-8.4.0.jar
   - src/
   - web/
   - data/
   - schema.sql
2. Commit your changes and push to your GitHub repository.

Step 3: Create Render Web Service
1. Log in to Render (https://render.com).
2. Click "New +" and select "Web Service".
3. Connect your GitHub repository.
4. Choose "Docker" as the runtime environment.
5. In the "Environment Variables" section, add:
   - Key: MYSQL_URL
   - Value: <your Aiven MySQL connection string>
6. Click "Create Web Service".

Step 4: Verify Deployment
1. Monitor the Render deployment logs.
2. Verify that the build completes and the Java server prints:
   "ARAM OFFICE - E-GOVERNANCE WEBSITE"
   "Website running on port: <assigned_port>"
3. Open the Render provided URL in your browser.
4. Test login, document search, 3-month filter, and PDF viewing.


8. TROUBLESHOOTING
- Database connection failure:
  Verify the MySQL host, port, user, and password. For Aiven, check that SSL
  is enabled (?sslMode=REQUIRED).
- Session expired message:
  If inactive or if cookies are cleared, the system redirects to login. Sign in
  again with valid credentials.
- Higher Official provisioning:
  Public registration creates Viewer accounts. Higher Official accounts must be
  provisioned using the local AdminProvisioner tool (or direct database insert)
  to ensure strict departmental controls.
